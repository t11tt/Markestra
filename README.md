# Markestra

**开网店用的操作系统。** 帮助商家管理商品、接待订单，并把同一份商品资料变成小红书、朋友圈和抖音的宣传文案与海报。

名字来自 market 和 orchestra：网店与宣传围绕同一套资料协同工作。目前重点是社交媒体物料生成，同时提供商品、购物车、订单与库存的基础闭环。

> 最新开发进度以 `main` 为准。最近标记版本是 `v0.3.0`；当前 `main` 已包含下述界面、DeepSeek、海报模板与库存更新。

## 快速启动

环境：Node.js 20.9+（本项目在 Node.js 22 下验证）、npm。

```bash
git clone https://github.com/t11tt/Markestra.git
cd Markestra/web
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。登录页可选择「以演示身份进入」，或创建自己的商家账号。示例网店是拾光食堂。

开发启动脚本会启动本机 PGlite PostgreSQL、生成 Prisma 客户端、应用数据库迁移并初始化演示资料，不需要另外安装 PostgreSQL。更新现有项目后，重新运行 `npm run dev` 即可应用新迁移。

## 当前功能

- **商品与网店**：编辑商品名称、描述、价格、图片、库存与上下架状态；顾客在独立网店选择商品、填写联系方式并下单。
- **购物车与订单**：购物车按店铺保存在当前浏览器。服务端按实际价格计价，在事务中扣库存；库存不足拒绝下单，取消订单只返库一次，已完成和已取消的订单不可倒退。
- **DeepSeek 文案**：依据品牌、商品、活动价格与日期，生成小红书笔记、朋友圈文案和抖音口播脚本；支持单渠道重新生成、编辑、确认与历史版本找回。
- **海报与素材包**：支持独立海报标题、实拍照片排版和 1080 × 1440 PNG 导出；全部素材以 ZIP 下载，包含各渠道的 PNG 海报与 TXT 文案，并保存导出记录。
- **运营记录**：登记发布、录入或导入指标、生成复盘并创建下一轮活动。演示数据单独标出，复盘不把互动指标当成销量证明。
- **统一界面**：奶油色、橄榄色与柠檬绿；动态背景线条、悬浮玻璃导航、卡片边缘高光与弹性动效，适配移动端及系统的「减少动态效果」设置。右上角 Logo 返回功能介绍。

场景模板与四套经典配色分组展示。每次完整生成或单渠道重新生成成功后，从五套新模板中选择背景，避免与当前背景连续重复；也可以手动挑选或点击「换一张」。选择保存在活动中，刷新后保留。

**生成方式**：DeepSeek API 生成文案；背景由 imagegen 预先生成并随项目提供；应用代码将背景、商家上传的照片、标题和价格排版成海报。日常生成不调用图片生成 API，也不自动重绘商家的商品。演示茶点图片为 AI 示例，实际商家请使用自己的实拍。

背景原稿与生成提示词见 [设计资料](web/design/poster-backgrounds/prompts.md)，运行时使用 `web/public/poster-backgrounds/` 内的 WebP 文件。

## 配置 DeepSeek

在本机 `web/.env` 中加入：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-flash
```

保存后重启开发服务器。密钥仅由服务端读取，不发送到浏览器。未配置密钥时使用本地演示生成；已配置但接口失败时会明确报错。旧千问配置仍兼容，配置方式见 [开发说明](web/README.md)。

`npm run dev` 会写入本机 `DATABASE_URL`，其余环境变量保留。`.env.example` 仅为配置样例。

## 验证

在 `web` 目录执行：

```bash
npm test
npm run lint
npm run build
```

开发服务器运行时，可额外执行 `npm run test:commerce`，在独立临时店铺验证并发下单、库存不足、取消返库和账号隔离，完成后清理测试店铺。真实文案和模板轮换验收脚本见 [开发说明](web/README.md)，运行这些脚本会调用已配置的模型 API。

## 当前边界

真实支付和物流服务尚未接入，下单不代表已付款。应用不会自动发布到小红书、朋友圈或抖音，也不会抓取这些平台的数据。购物车暂不跨设备同步。

新增商品默认库存为 100；库存功能迁移会将已有商品初始化为 100，请按实际库存调整。开发启动脚本面向本机演示，线上部署需要另行配置数据库、文件存储、密钥与支付物流服务。

本地数据库和上传文件位于 `web/data/`，API 密钥位于 `web/.env`，均不提交 Git。不要复制他人电脑上的 `web/data`；共享演示资料以迁移与种子脚本为准。
